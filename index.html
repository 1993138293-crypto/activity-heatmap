欢迎使用活动热力图

· 类似 GitHub 贡献图，用颜色深浅记录每天的活动强度（时长越久颜色越深）
· 点击任意日期，添加或编辑当天的活动记录
· 支持标签分类筛选，按「运动 / 学习 / 健康」等维度查看
· 设置每日提醒，到点提醒你打卡
· 顶部自动统计年度活动天数、连续打卡等数据
· 支持月 / 年两种视图，左右滑动浏览历史
